LTI 1.3 Demo Tool

A minimal LTI 1.3 tool: OIDC third-party initiated login, id_token validation against the platform's keyset, Deep Linking content selection, and a published JWKS.

Registration values

These are what an LMS administrator needs when adding this tool.

Tool base URL
OIDC login initiation URL
Redirect / target link URI
Public JWKS URL

Several platforms compare the redirect URI by exact string match. A trailing slash on one side and not the other is a failed launch with an unhelpful error.
